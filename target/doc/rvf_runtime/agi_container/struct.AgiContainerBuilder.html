Expand description

Builder for assembling an AGI cognitive container manifest.

The manifest is a META segment in the RVF file. Other segments (KERNEL_SEG, WASM_SEG, VEC_SEG, etc.) are added through the main RVF write path; this builder only handles the manifest.
