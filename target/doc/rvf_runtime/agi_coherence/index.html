Coherence monitoring and container validation pipeline (ADR-036).

This module provides two main components:

  • CoherenceMonitor: tracks real-time coherence state across events, contradictions, and task rollbacks, transitioning through CoherenceState to gate commits, skill promotion, and autonomous execution.

  • ContainerValidator: runs the full validation pipeline over an AGI container’s header, segments, and coherence thresholds, collecting all errors rather than short-circuiting.
